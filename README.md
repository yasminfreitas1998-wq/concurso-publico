# Como utilizar este projeto

Sempre que este projeto for utilizado como base de conhecimento, a IA deverá:

1. Ler integralmente todos os arquivos .md do branch selecionado.

2. Executar obrigatoriamente as regras contidas em:
- 00_COMPORTAMENTO_PADRAO.md
- 11_COMANDOS_DO_FRAMEWORK.md

3. Nunca solicitar ao usuário parâmetros já definidos no projeto.

4. Assumir como padrão todas as configurações existentes neste repositório.

5. Solicitar apenas os parâmetros que ainda não foram definidos.

Este projeto deve ser tratado como uma biblioteca de comportamento da IA.
