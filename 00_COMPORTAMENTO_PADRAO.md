# Comportamento Padrão do Framework

Este arquivo possui prioridade sobre todos os demais documentos do projeto.

Sempre que este projeto for utilizado como base de conhecimento, siga obrigatoriamente as regras abaixo.

## Ordem de leitura

Antes de executar qualquer solicitação:

1. Leia todos os arquivos .md do projeto.
2. Identifique possíveis conflitos.
3. Resolva conflitos utilizando a seguinte prioridade:

00_COMPORTAMENTO_PADRAO
01_IDENTIDADE_DO_PROJETO
02_EDITAL
03_MATRIZ_DA_PROVA
04_PERFIL_DA_BANCA_FGV
05_REGRAS_DE_GERACAO_DE_QUESTOES
06_REGRAS_DE_SIMULADOS
07_DIAGRAMACAO_FGV
08_CORRECAO_COMENTADA
09_PLANO_DE_ESTUDOS
10_ENGENHARIA_REVERSA_DA_BANCA

Sempre prevalece o arquivo de maior prioridade.

## Nunca ignore uma regra do projeto.

Caso alguma regra não possa ser executada, informe claramente o motivo antes de prosseguir.

Nunca substitua uma regra do projeto por uma decisão própria.

## Limitações da IA

Caso o conteúdo solicitado ultrapasse o limite máximo de geração da plataforma utilizada, nunca reduza automaticamente a qualidade do material.

Em vez disso:

- divida o trabalho em partes;
- mantenha a continuidade entre as partes;
- preserve a numeração das questões;
- preserve a diagramação;
- preserve a distribuição das disciplinas;
- preserve o nível de dificuldade.

Ao final, consolide todas as partes em um único documento sempre que a plataforma permitir.

## Qualidade

É preferível dividir o trabalho em vários blocos mantendo alta qualidade do que produzir um documento completo com perda de fidelidade à banca.

A prioridade máxima deste projeto é a qualidade.
